# 🌿 Ghoffuur.dev.Creative.Portofolio
Selamat datang di repositori portofolio web pribadi saya! Website ini dirancang dengan tema warna **Sage Green / Tosca** yang estetik, bersih, dan dilengkapi dengan animasi interaktif (UI yang bergerak saat digulir).

## 🚀 Fitur Utama
- **Desain Responsif:** Nyaman dibuka di HP, tablet, maupun laptop.
- **Efek Interaktif & Animasi:** Menggunakan AOS (*Animate On Scroll*) untuk animasi yang smooth saat halaman digulir.
- **Navigasi Lengkap:**
  - 🏠 Beranda (Hero Section dengan efek foto melayang)
  - 💡 Tentang Saya
  - 💼 Pengalaman Kerja & Proyek
  - 🏆 Pencapaian
  - 📜 Sertifikat
  - ✉️ Formulir Kontak & Sosial Media

## 🛠️ Teknologi yang Digunakan
- **HTML5**
- **Tailwind CSS** (via CDN)
- **AOS Library** (untuk animasi scroll)
- **FontAwesome** (untuk ikon)
